Drop the official PSHS logo in this folder, named exactly:

    pshs-logo.png

A square PNG with a transparent background works best, around 256x256.
An SVG also works if you rename the reference in templates/index.html.

Until that file exists, the header shows a plain "PS" monogram instead.
Nothing breaks either way -- the <img> removes itself if the file is
missing and the monogram takes over.

I could not include the real logo myself: it is the school's own mark and
is not something I should reproduce from memory or generate an imitation
of. Take it from your school's official letterhead or website.
