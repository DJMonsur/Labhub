# ── Serverless Postgres (Vercel / Neon) ──────────────────────────────────────
# Setting DATABASE_URL in .env switches the app to PostgreSQL. psycopg
# ships prebuilt binary wheels for Linux (3.12–3.14), so it installs cleanly
# on Vercel — unlike mysqlclient, which has no Linux wheel and cannot compile
# in Vercel's build image. Unused locally (SQLite) but harmless.

# ── NOTE ─────────────────────────────────────────────────────────────────────
# mysqlclient is deliberately NOT here. The app defaults to SQLite, which needs
# no database server, and mysqlclient ships no prebuilt wheel for Linux — pip
# tries to compile it from source and fails unless you have MySQL's C headers
# installed. That single package was the reason a plain `pip install -r
# requirements.txt` used to break.
#
# Only if you set DB_ENGINE=mysql in .env:
#     pip install -r requirements-mysql.txt
