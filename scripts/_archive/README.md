# Archived scratch scripts

These were one-off scripts sitting in the project root. They are not tests and
nothing in the app imports them — they're kept here only so no work is lost.

`fix.py` is the one to be careful with: it opens `inventory/views.py`, rewrites
it in place, and has no backup step. Do not run it.

Delete this folder once you've confirmed you don't need anything in it.
